# GF 40 MHz 独立实验版

本实验将 v6 的系统时钟降至 40 MHz，并使用同一 RTL 和固定构建环境验证时序变化。最终结论以布局布线后的全部九个角报告及功能检查为准。

## 配置与启动

- 时钟周期为 25 ns，输入输出延迟预算均为 2.5 ns。
- RTL 字节保持一致，源码中 80 MHz 的注释描述原基线；实验工作频率以本项目配置为准。
- 档位编码为 0 至 23；第一次合法配置在复位释放后锁存，第一采样发生于完整分频间隔之后。
- 80000 拍启动交接在 40 MHz 下约为 2 ms；FPGA 应按该时刻提前释放 uio[0]。
- 交接仅表示方向改变，完整窗口需要 2048 个有效采样及后端流水线。模拟链路开始输出后还需要重新等待完整有效窗口。
- 输出类型每个系统时钟切换，面积和峰值各占一拍，FPGA 读取接口应按 40 MHz 时序核对。

## 验收与验证范围

全部九个角 Setup 和 Hold 无负余量才判为时序通过；转换时间、负载、扇出及物理检查通过才判为完整通过。失败日志仍需保存。

门级功能回归不含 SDF。理想正弦的 90 度偏置测试及 FPGA 启动对齐测试证明数字逻辑行为；实际 FPGA、ADC、模拟延迟、管脚封装和实物验证需要另行完成。

构建环境与原 80 MHz 运行固定一致，记录见 build_lock.json。原 v6 和 GitHub main 保留原样，实验分支不发布展示页面。
